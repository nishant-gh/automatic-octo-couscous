```bash
git clone https://github.com/nishant-gh/automatic-octo-couscous.git
cd automatic-octo-couscous
# Extension is ready to load!
```

**Option 2: Download ZIP**
1. Download repository as ZIP
2. Extract to folder
3. Load in Chrome

**Option 3: Use Existing Files**
- All files already generated
- Icons already created
- Ready to load immediately

### Loading in Chrome

1. Enable Chrome AI flags (`chrome://flags`)
2. Go to `chrome://extensions/`
3. Enable Developer mode
4. Click "Load unpacked"
5. Select project folder
6. ✅ Extension active!

### Testing

1. Click extension icon → popup opens
2. Click "View Dashboard" → full interface
3. Open `demo-test-page.html` → test scenarios
4. Browse normally → real-time protection
