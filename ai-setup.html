Enable AI Features

Get the most out of GuardianAI with Chrome's Built-in AI
⚠️
AI Features Not Available
GuardianAI is using pattern-based detection only. Follow the steps below to enable full AI protection.
✅
AI Features Enabled!
GuardianAI is now using Chrome's Built-in AI for advanced scam detection.

Setup Steps

Download Chrome Dev or Canary
Chrome's Built-in AI requires Chrome 128+ or Chrome Dev/Canary channel.
chrome://version
Check your version. If below 128, download Chrome Dev or Canary.
Enable AI Flags
Open Chrome flags and enable the AI features:
chrome://flags
Search for and enable:
  • "Prompt API for Gemini Nano" → Set to "Enabled"
  • "Rewriter API" → Set to "Enabled"
Restart Chrome
Click the "Relaunch" button that appears at the bottom of the flags page. Chrome will restart with AI features enabled.
Wait for Model Download (First Time)
The first time AI is used, Chrome downloads the language model (~1-2GB). This may take 10-30 minutes depending on your connection.
💡 Tip
Keep Chrome open while downloading. You can check progress in DevTools Console.
Verify AI is Working
Open Chrome DevTools (F12) and run this in Console:
ai.languageModel.capabilities().then(c => console.log(c))
You should see available: "readily" when ready.
Reload GuardianAI
Reload the GuardianAI extension to activate AI features:
chrome://extensions/
Find GuardianAI and click the reload icon.

Alternative: Pattern-Based Detection

Don't want to set up Chrome AI? GuardianAI still works with pattern-based detection! It will detect common scam indicators like urgency language, suspicious requests, and known scam patterns.

AI features provide more sophisticated analysis and better detection of subtle scams, but pattern-based detection still offers significant protection.
